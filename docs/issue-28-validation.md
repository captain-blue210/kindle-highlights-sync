## 対象選別と状態保存

通常同期でもNotebookの一覧を毎回読み込み、一覧の取得完了を確認してから注釈の取得対象を選ぶ。新規書籍、注釈日の変更、前回同期日の前日以降、日付不明、取得または保存の未完了を対象にする。注釈日はUTCで表した暦日、同期日は同期開始時の端末の暦日として比較する。前日の計算にはUTCの暦日演算を使う。

`bookSyncState` はリージョン・ASINごとに注釈日、取得状態、保存状態、出力フォルダ、明示的な同期先の識別情報を保持する。取得前に対象をpendingとして永続化し、その保存が失敗したら注釈を取得しない。取得終了後も保存状態はpendingのまま。writerのcreated/updated結果を受け、完了記録の永続化に成功してからメモリ上の完了状態を確定する。保留、取得・保存失敗、保存結果のない書籍は再取得対象に残る。

通常の設定保存キューは、実行時点の確定済み台帳を読み直す。遅れて実行された設定保存が新しい完了記録を消したり、失敗した仮の完了記録を確定したりしない。注釈も既存ノートもない書籍は保存完了とせず、取得のみ成功の状態で再取得する。保存先の変更や明示指定の無効化も再確認する。

対象選別にObsidian本文を使わない。既存の注釈対応付け・保存先指定・追記処理をそのまま使用する。全件取得コマンドは選別を迂回し、一覧の全書籍を処理する。

## 自動検証で確認した範囲

| 条件 | 確認結果 |
| --- | --- |
| 古い注釈日で取得・保存が完了した書籍 | 通常同期で注釈ページを取得せず、一覧は再確認する |
| 新規・注釈日変更・前日境界・日付不明 | 対象に含む。日付が過去へ変わった場合、年をまたぐ前日も確認 |
